## 实践练习: 使用 Portainer 对 docker 进行可视化管理

## 一、Portainer 简介

### 1. 是什么？

Portainer 是一个轻量级的 Docker 管理工具，提供了直观的 Web 界面来管理 Docker 环境。主要功能如下：

<table>
  <tbody>
    <tr>
      <td align="center"><b>仪表盘概览</b></td>
      <td align="left">- 查看环境整体状态<br>- 监控资源使用情况<br>- 查看事件日志</td>
    </tr>
    <tr>
      <td align="center"><b>容器管理</b></td>
      <td align="left">- 创建、启动、停止、删除容器<br>- 查看容器日志和统计信息<br>- 进入容器终端<br>- 修改容器配置</td>
    </tr>
    <tr>
      <td align="center"><b>镜像管理</b></td>
      <td align="left">- 拉取和删除镜像<br>- 构建新镜像<br>- 推送镜像到仓库</td>
    </tr>
    <tr>
      <td align="center"><b>网络管理</b></td>
      <td align="left">- 创建和管理 Docker 网络<br>- 配置容器网络连接</td>
    </tr>
    <tr>
      <td align="center"><b>数据卷管理</b></td>
      <td align="left">- 创建和删除数据卷<br>- 管理数据卷权限</td>
    </tr>
  </tbody>
</table>


### 2. 安装 Portainer

```bash
# 创建 Portainer 数据卷
docker volume create portainer_data

# 运行 Portainer 容器
docker run -d -p 9000:9000 \
    --name portainer \
    --restart=always \
    -v /var/run/docker.sock:/var/run/docker.sock \
    -v portainer_data:/data \
    portainer/portainer-ce:2.29.2
```

安装完成后，在 cnb 上我们可以通过添加一个 9000 的端口映射来实现外网访问, 可以按照如下步骤来配置。
